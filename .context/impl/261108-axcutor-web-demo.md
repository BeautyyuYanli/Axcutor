- Playground 将浏览器本地编译、CFG 调试与 HTTP 执行组合为使用原生控件的单页工作台。
  - 多文件 YAML/JSON 源码、入口与原始 Input 可独立编辑；默认示例直接复用仓库资源。WASM 实时执行静态编译，诊断可定位文件、作用域与节点。
  - CFG 展示 Root Run、分支、catch、Fork-Join 与内联图，支持作用域导航、节点静态探针、变量投影和子类型过滤。运行帧与画布可双向选择，并显示活跃节点、连边和并发迭代。

- 编译与执行边界保留原始 JSON，维持任意精度数值、integer/number 类别及对象键序。
  - Input 原文直接嵌入提交信封；帧变量、最终输出与错误详情按原始 token 提取，仅调整展示空白。重复键、非有限数值、非法 JSON 和非对象 Input 在提交前报错。
  - 静态探针将原始 analysis 文本交回 WASM，保留类型枚举中的数值与键序。宿主新增 `GET /openapi.json` 和静态导出入口，由同一 OpenAPI 3.1 定义生成客户端；执行继续使用现有三个 `/v1/executions` 接口及结构化错误信封。

- 页面拥有编辑状态与提交快照，Temporal 拥有持久执行及历史。
  - 编辑状态保存在页面内存，刷新后恢复默认示例。提交快照固定运行拓扑；执行期间继续编辑源码时，可在当前编译结果与提交快照之间切换，点击运行帧会使用对应快照定位。
  - 每次查询完成后等待 300ms 再轮询，慢请求不会重叠。取消返回 `202 / running` 时继续观察，直到终态；终态停止定时器并中止在途观察请求，迟到响应不会覆盖终态。页面释放仅停止观察，后端执行继续存在。

- 开发与生成入口可从仓库重现，静态部署通过同源转发连接 HTTP 宿主。
  - `npm --prefix playground run generate` 导出 OpenAPI、生成客户端和浏览器 WASM，`build` 生成静态产物。首次检出需准备匹配的 Rust/WASM 工具链并执行生成；WASM 与构建产物不纳入版本控制。
  - 开发页面默认位于 `127.0.0.1:5173`，代理 API 至 `127.0.0.1:8000`；静态部署需配置 `/v1` 转发。完整环境、启动与部署说明见 `manual/docs/guide/00-web-playground.md`。
