Workspace files 与 Editor 可独立收起和恢复，两个区域都收起时画布占满主工作区。折叠保留未保存内容、光标、滚动位置与执行观察；点击文件、新建成功或定位诊断会展开编辑区。

运行面板持续显示提交、观察、运行、等待信号、取消和终态，并单独解释 workspace 忙或清理期间的只读状态。当前步骤与所选步骤数据分区展示，主动选择跨轮询保留，步骤消失后改选真实当前步骤。成功结果和失败原因优先展示，执行 ID 与时间收纳在次要详情中，业务字段保留原始数值精度和顺序。

TypeSpec、静态探针、入口类型契约和派生端口表已从界面移除。画布保留节点名称、分支、导航、运行标记以及简短的并行、重试和超时行为说明。
