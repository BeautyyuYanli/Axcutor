心跳超时默认改为 `30000ms`；省略心跳间隔时，按 `max(1, T // 3)` 派生，默认得到 `10000ms`。显式间隔保持原值，两个参数必须是正整数且满足 `I < T`；显式 `None`、布尔值及无效关系被拒绝。

`ExecutionService(options=...)` 在构造时校验运行选项，错误抛出 `ValueError`，仅复制并持久化原始覆盖字典。Workflow 在执行或重放时补齐默认值；直接请求的非法选项成为不可恢复的 `EngineError`。Child 接收父 Run 展开后的完整选项；已有 Activity 及其原生重试保留历史参数，恢复后的新调度采用当前缺省值，已启动的 Child 保留旧值。

`create_worker(..., **kwargs)` 恢复 SDK 的心跳节流默认值，并允许宿主透传覆盖。Playground 显式配对 `200ms` 应用心跳与最大节流间隔，保留 `30000ms` 失活检测窗口。生产默认降低心跳 RPC 频率，同时接受数十秒量级的取消送达等待。

取消和超时仍等待任务清理；Playground 只有在 Temporal 终态且本地执行器排空后才解锁，关闭 Worker 后再卸载模块并释放工作区。快速心跳增加取消送达机会，不保证固定时间内完成清理或停机。
